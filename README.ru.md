# NEAR Analyzer Bot

- **Сканер токенов** (как в near-dex-bot): пришли адрес токена или ссылку nearly / JustHoot / DexScreener, или `/scan адрес` — цена, FDV, ATH, ликвидность, объём, топ-10 холдеров со ссылками на кошельки, свечной график 15m.
- **Алерты в темах группы**: DEX Paid (оплата профиля на DEX Screener + одобрение), бусты, CTO, реклама. Мемпады nearly и JustHoot: токен достиг капитализации $10K / $20K / $30K, дипы −15% и больше.

## Установка на VPS (Termius)

```bash
cd /root
git clone https://github.com/LoveTon-crypto/near-analyzer-bot.git
cd near-analyzer-bot
printf 'BOT_TOKEN=ваш_токен\nPOLL_SECONDS=20\n' > .env
bash deploy.sh
```

## Обновление

Загрузи на GitHub новый `near-analyzer-bot.zip` (заменив старый) или сами файлы, потом:

```bash
analyzer-update
```

## Владелец

Первый, кто напишет боту `/start` в личке, становится владельцем: только он видит админ-панель (`/admin`) и может настраивать темы. Можно задать вручную строкой `OWNER_ID=ваш_id` в `.env`.

## Настройка группы

1. Группа → Настройки → включить «Темы».
2. Добавить бота админом.
3. В нужной теме отправить команду:

| Тема | Команда |
|---|---|
| DEX Paid | `/settopic dexpaid` |
| Бусты | `/settopic boost` |
| CTO | `/settopic cto` |
| Реклама | `/settopic ads` |
| MC $10K | `/settopic 10k` |
| MC $20K | `/settopic 20k` |
| MC $30K | `/settopic 30k` |
| Дипы | `/settopic dip` |

`/topics` — привязки, `/test dexpaid` — тестовый пост, `/unsettopic boost` — отвязать.

Сканер работает в любой теме и в личке с ботом. Под каждым алертом есть кнопка 🔎 Scan — она присылает полную карточку токена.

Уровни и пороги меняются в `.env`: `MCAP_LEVELS=10000,20000,30000`, `DIP_PCT=15`, `DIP_WINDOW_MIN=60`, `DIP_MIN_LIQ=300`.

## Коллы

В группе первый, кто скинул контракт токена, получает колл: бот запоминает его и капитализацию в этот момент.
Под карточкой токена: строка «🎯 Called by … · было → сейчас · ATH с колла» и кнопка **📊 PnL** — картинка с результатом колла.
`/callers` — лучшие коллеры группы (кнопки 24H / 7D / 30D / ALL), рейтинг по ATH с момента колла.

## Свои картинки для PnL

Положи .png/.jpg в `pnl_images/win` (для профита) и `pnl_images/loss` (для минуса) — бот будет случайно выбирать их наравне со встроенными.

## Посты из X

1. Зарегистрируйся на twitterapi.io, скопируй API key (дают $1 бесплатно).
2. На сервере: `echo 'TWITTERAPI_KEY=твой_ключ' >> /root/near-analyzer-bot/.env && systemctl restart near-analyzer`
3. В теме для X: `/settopic x`, затем `/xadd ilblackdragon NEARProtocol` (можно ссылками на профиль).

`/xlist` — список, `/xdel имя` — убрать. Опрос раз в 2 минуты (`X_POLL_SECONDS`), примерно $3–4 в месяц на все аккаунты.
Ответы (replies) по умолчанию не присылаются: `X_INCLUDE_REPLIES=1` чтобы включить; репосты — `X_INCLUDE_RETWEETS=0` чтобы выключить.

## Ежедневный топ

`/settopic daily` в нужной теме — каждый день в 18:00 по Минску бот присылает топ-5 выросших и топ-3 упавших за 24ч (текст со ссылками + картинка-таблица с иконками, FDV, объёмом, изменением).
Берутся токены nearly / JustHoot и токены, которые коллили в группе; мусор с ликвидностью < $500 или объёмом < $100 пропускается.
`/digest` — прислать прямо сейчас. Настройки в `.env`: `DIGEST_TIME=18:00`, `DIGEST_TZ=Europe/Minsk`, `DIGEST_MIN_LIQ`, `DIGEST_MIN_VOL`, `DIGEST_GAINERS=5`, `DIGEST_LOSERS=3`.

## Курс NEAR

`/near` — актуальный курс $NEAR (CoinGecko) и свечной график (Kraken), кнопки 1D / 7D / 30D и 🔄. Работает у всех, в группе и в личке.

## Топы

- `/top` — топ-10 токенов nearly + JustHoot по объёму за 24ч
- `/topmc` — топ-10 по капитализации (токены с ликвидностью от $300)
- `/topdex` — топ-10 «горячих» родных токенов NEAR по данным DexScreener (объём и сделки за 6ч/1ч, давление покупок, рост, бусты). Мейджоры, стейблы и токены через мосты (ETH, SOL, BTC, XRP, ZEC, USDC, wNEAR…) исключены. Точной вкладки Hot у DexScreener в открытом API нет — это максимально близкая замена.

Под списком кнопки 📊 Volume / 💰 MCap / 🔥 Trending — переключают список в том же сообщении.

## Канал новых деплоев

Бот читает каждый блок NEAR и ловит момент, когда на nearly или JustHoot создаётся новый токен. В канал уходит пост:
аватарка монеты, название, тикер, описание, кошелёк дева, его баланс NEAR, сколько токена держит дев,
прошлые деплои с этого кошелька и лучший ATH среди них. Кнопки: 🟢 Buy on Bettear (с реф-кодом), ⚡ Buy on NDbot (наш трейд-бот [@ndegen_bot](https://t.me/ndegen_bot), [репозиторий](https://github.com/LoveTon-crypto/near-trade-bot)), страница
мемпада, 🔎 Scan (открывает полный скан в личке с ботом), 👤 Dev.

1. Создай канал и добавь бота админом с правом публиковать сообщения.
2. В личке с ботом: `/setdeploys @имя_канала` (для приватного канала — его id `-100…`).
3. `/deploys` — статус (какой блок читается, сколько деплоев в базе). `/deploytest адрес` — пример поста в личку.

История девов копится с момента запуска. Чтобы сразу учесть старые деплои, добавь в `.env` строку
`BACKFILL_DAYS=7` и перезапусти бота: он один раз в фоне пройдёт блоки за 7 дней (примерно час на каждый день,
постов при этом не будет).

Настройки в `.env`: `BETTEAR_REF=ref-1094156325` (твой реф-код), `DEPLOY_DELAY=12` (сколько секунд ждать
после деплоя, чтобы успела пройти первая покупка дева), `DEPLOY_EXTRA_FACTORIES=` (новые мемпады через запятую).
